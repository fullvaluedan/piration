Piration — Privacy Policy

Last updated: 2026-08-06

Piration is an offline pirate RPG. Game progress is stored only on your device (local app storage). We do not operate game servers that receive your save data.

Data we collect

The app does not require an account and does not intentionally transmit personal data to us. If you install via Google Play, Google may process install analytics under their policies.

Permissions

No special permissions are required for core offline play. Future updates will list any new permissions here.

Children

The game is a light fantasy pirate title. Configure Play target age appropriately. No social features in the current build.

Contact

Open an issue on the GitHub repository: github.com/fullvaluedan/piration

Upstream

Piration is an independent archive port inspired by open-sourced Pirate Nation materials. Not affiliated with Proof of Play.
